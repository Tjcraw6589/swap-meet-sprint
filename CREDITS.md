# Credits

Swap Meet Sprint is made by Bal Tak.

* Every item, maker, band, artist and title in the game is invented. Any likeness to a real product is accidental.

* Font: to be chosen in Milestone 2. It will be an open licence pixel font, bundled, with its licence file copied next to it and listed here.
